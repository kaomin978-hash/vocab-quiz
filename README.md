# 📘 每日單字測驗（方案 A：單檔 Streamlit Web App）

用手機瀏覽器打開就像個 App。單字庫放在 Google Sheet，隨時用手機編輯，App 立刻同步。

```
單字APP/
├── app.py              ← 整個 App，就這一支
├── sample_vocab.csv    ← 內建範例單字庫（47 字，含 17 個熟詞偏義）
├── requirements.txt
├── .streamlit/config.toml
└── progress.json       ← 學習紀錄（自動產生，本機執行才會保留）
```

---

## 1. 本機執行

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

瀏覽器會自動打開 http://localhost:8501。
同一個 Wi-Fi 下，手機輸入終端機顯示的 `Network URL`（例如 `http://192.168.x.x:8501`）就能直接用。

## 2. 單字庫格式

表頭用**中文或英文都可以**，缺的欄位會自動補空白，順序不拘。

| 欄位 | 別名 | 必填 | 說明 |
|---|---|---|---|
| `word` | 單字 / 英文 | ✅ | 英文單字或片語 |
| `meaning` | 中文意思 / 中文解釋 / 意思 / 釋義 / 中譯 | ✅ | 中文解釋 |
| `pos` | 詞性 | | `v.` `n.` `adj.`…，用來讓干擾選項**同詞性**，題目更有鑑別度 |
| `example` | 例句 | | **有例句才能出填空題**，強烈建議填。中英文寫在同一格也可以，見下方說明 |
| `example_zh` | 例句翻譯 | | 答題後顯示 |
| `note` | 備註 / 說明 | | 熟詞偏義的說明寫這裡 |
| `tags` | 標籤 / 分類 | | 填 `熟詞偏義` 會被特別標註，並可用「熟詞偏義特訓」模式單獨練 |

標籤和備註**寫在同一欄也可以**（欄名叫 `標籤 / 備註`、`標籤備註` 都認得），用 `【】` 把標籤框起來放在最前面：

```
【熟詞偏義】常見意思是「硬的」，多益常考「競爭激烈（stiff competition）」
```

App 會拆成 `tags = 熟詞偏義`、`note = 常見意思是…`。方括號 `[]` 或全形 `［］` 也可以。

範例（照抄 `sample_vocab.csv` 的格式即可）：

```csv
word,meaning,pos,example,example_zh,note,tags
address,處理、著手解決,v.,The committee will address the safety concerns.,委員會將處理安全疑慮。,常見意思是「地址」，多益裡多半當動詞。,熟詞偏義
```

> 標題含「熟詞偏義 / 偏義 / 陷阱 / tricky」任一關鍵字（寫在 `tags` 或 `note` 都算），
> 該字在答題後會跳出 ⚠️ 橘色警示框，並被歸入「熟詞偏義特訓」模式。

### 例句與翻譯放在同一格也 OK

很多人的單字表會這樣寫：

```
Commercial realtors reported an increase in demand. (商用房地產經紀人報告稱，需求有所增加。)
```

App 會自動把句尾括號裡的中文拆到 `example_zh`（沒有括號、中文直接接在英文後面也認得）。
**這一步是必要的**：不拆的話，填空題的中文翻譯會緊跟在空格旁邊，等於把答案送給你。
如果你另外開了 `例句翻譯` 欄，App 就以那一欄為準，不會動你的例句。

## 3. 接上你的 Google Sheet

1. 把單字整理進 Google Sheet，第一列是表頭（用上表的欄位名）。
2. 右上角 **共用 → 一般存取權 → 知道連結的任何人 → 檢視者**。
3. 複製網址列的連結，貼進 App 側邊欄的「Google Sheet 連結」。

App 會自動把 `.../edit#gid=0` 轉成 `.../export?format=csv&gid=0`，不需要 API 金鑰、不需要 OAuth。
資料快取 10 分鐘；在 Sheet 改完字後按側邊欄的「🔄 重新載入單字庫」即可立刻生效。

**想讓連結變成預設值**（免得每次貼），建立 `.streamlit/secrets.toml`：

```toml
sheet_url = "https://docs.google.com/spreadsheets/d/你的ID/edit#gid=0"
```

（部署到雲端時，改在 Streamlit Cloud 的 **Settings → Secrets** 貼同一行。）

## 4. 部署到 Streamlit Community Cloud（免費）

1. 把這個資料夾推上 GitHub（**`progress.json` 不要推**，見 `.gitignore`）。
2. 到 <https://share.streamlit.io> → **New app** → 選 repo、branch，Main file 填 `app.py` → Deploy。
3. 約一分鐘後拿到 `https://你的名字-單字app.streamlit.app` 這樣的網址。
4. 手機打開該網址 → **加到主畫面**（iOS Safari 的分享鍵 / Android Chrome 的選單），
   之後點桌面圖示就是全螢幕開啟，跟原生 App 幾乎一樣。

> ⚠️ 雲端容器的檔案系統是暫時的，`progress.json` 在重新部署／休眠後會清空。
> 想長期保留紀錄，用側邊欄的「⬇️ 下載學習紀錄 JSON」自行備份即可。
> 若 Sheet 想保持非公開，就得改用 Google Sheets API + service account（把金鑰放進 Secrets），
> 但公開唯讀的 Sheet 已足夠應付單字庫這種用途，且省掉一整包設定。

## 5. 功能

**四種題型**（側邊欄可自由勾選組合）

| 題型 | 內容 |
|---|---|
| 英 → 中 | 看單字選中文意思 |
| 中 → 英 | 看中文選英文單字 |
| 例句填空（四選一） | 例句中的目標字挖成 `＿＿＿＿＿`，四選一 ← **最接近多益 Part 5** |
| 例句填空（拼字輸入） | 同上但用打字作答，`approved` / `approve` 都算對 |

**四種模式**

- **每日精選** — 以日期為亂數種子，同一天不管重整幾次、換幾支裝置，題目都一樣（今天沒做完可以接著做）。
- **自由練習** — 每次重新抽。
- **錯題複習** — 只考錯題本裡的字；**同一個字連續答對兩次**才會從錯題本畢業。
- **熟詞偏義特訓** — 只考標記了熟詞偏義的字。

**干擾選項的產生邏輯**（`pick_distractors()`）

優先從**同詞性**的字抽 → 不夠再從**同標籤**抽 → 還不夠才從全庫隨機抽。
同詞性的干擾項不會因為詞性明顯不合而被輕易刪去，鑑別度較高；
而且錯誤選項全部來自你自己的單字庫，答題時**順便複習到其他字**。
選項保證去重、不與正解重複；錯題複習與熟詞偏義模式下，干擾選項仍取自**完整**單字庫。

**其他**

- 答完立刻回饋：**四個選項全部附上釋義**（中文選項配英文字、英文選項配中文意思），
  另有正解、詞性、例句（目標字橘色標示）、例句翻譯、熟詞偏義提醒。
- 結果頁：正確率、錯題清單（可展開看例句）、**下載錯題 CSV**、一鍵重練這回錯字。
- 側邊欄：今日作答／答對數、**連續學習天數**。
- 手機優化：按鈕加高、字級放大、側邊欄預設收合。

## 6. 常見調整

| 想改什麼 | 改哪裡 |
|---|---|
| 每回預設題數 | `app.py` 的 `st.sidebar.slider("每回題數", 5, 40, 12)` 第三個數字 |
| 預設題型 | `DEFAULT_KINDS` |
| 熟詞偏義的判定關鍵字 | `TRICKY_KEYWORDS` |
| 新增欄位別名（例如你的表頭叫「英文字」） | `COLUMN_ALIASES` |
| 錯題畢業門檻（預設連對 2 次） | `record_result()` 裡的 `entry["streak"] >= 2` |
| 快取時間（預設 10 分鐘） | `@st.cache_data(ttl=600, ...)` |
